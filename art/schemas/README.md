# Schemas

This directory holds validation schemas for AI-assisted asset source files.

- `vector-asset.schema.json` describes approved vector source specifications
  for ships, asteroids, and bullets.
- `media-asset.schema.json` describes approved raster presentation assets,
  visual-effect sprites, and short audio effects.

Use the validator documented in
[the asset pipeline contract](../../docs/asset-pipeline.md) before promoting a
generated candidate.
