# Asset experiments

Use this folder for short, reviewable experiment records. Large generated
payloads, provider caches, and rejected bulk output should stay local and
untracked.

Each record should capture:

- goal
- prompt file and revision
- provider/tool and model
- date and seed
- candidate files reviewed
- gallery/contact-sheet evidence when useful
- problems found
- manual cleanup performed
- promotion or rejection decision
- provenance and commercial-use cautions

Start from [templates/experiment-record.md](templates/experiment-record.md).
